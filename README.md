# 人森拼豆色盘对照表

用于查看拼豆 221 色在《Tomodachi Life 朋友收集梦想生活》（トモダチコレクションわくわく生活）游戏自订色盘中近似位置的静态网页。

访问地址：

```text
https://twocloudsinthesky.github.io/tomodachi-color-guide/
```

## 内容

本项目提供按色号浏览、搜索、定位和对比功能，帮助在不能直接输入坐标的游戏界面中更快找到目标颜色。

项目亮点：

1. 支持两种颜色对比，并给出从颜色 A 调到颜色 B 时的色相条、色盘 X/Y 移动方向提示。
2. 定位图在电脑浏览器环境下尽量接近 NS1 游戏色盘截图尺寸，方便把网页与游戏画面并排进行手动比对。
3. 增加色相条按键次数参考，可查看从最右端开始大约需要按几次 `ZL`。

其他功能：

- 按 A/B/C/D/E/F/G/H/M 分组浏览 221 个拼豆色号
- 搜索色号、HEX、RGB
- 查看每个色号的游戏色盘定位图
- 查看底部色相条位置、上方色盘 X/Y 与 HSV 信息
- 适配电脑、平板和手机浏览器

## 校正说明

初始位置先由色块的 RGB/HSV 数值换算得到；随后在游戏中逐一选取与原拼豆色块视觉上最接近的颜色，记录实际色盘落点，并与初始 HSV 落点对比。最终色盘图会优先采用这些实测位置，用来修正单纯数学换算带来的偏差。

本项目的色块显示与人工比对环境为 MacBook Pro 2022，显示器颜色描述文件使用系统内建的“彩色 LCD”。不同设备、屏幕亮度或色彩模式下，观感可能略有差异。
