如何在游戏里使用

1. 先调底部色相条

查看图片里的 Hue bar 百分比，把游戏底部滑块移动到同一相对位置。

2. 再调上方色盘落点

Square X 是横向位置，越右越鲜艳；Square Y 是从上往下的位置，越下越暗。

3. 灰白黑色优先看明度

低饱和色的色相影响很小，主要把上方落点放在左侧，再调整上下明暗。

换算逻辑

底部色相条采用反向 HSV 色相：红、品红、蓝、青、绿、黄、红。上方色盘位置采用 ColorCraftLab 的经验校准，混合 HSV 与 HSL，使位置更接近游戏界面的视觉表现。

Hue bar = ((360 - HSV_H) % 360) / 360
Square X = HSV_S * 0.78 + HSL_S * 0.22
Square Y = 100 - (HSV_V * 0.68 + HSL_L * 0.32)

ZL 步长参考

根据 00 到 04 与 A6 的实测截图，滑块最右可达位置约为色相条 98.1%，每按一次 ZL 约向左移动 0.486%。因此色卡详情里的“从最右按 ZL 约 N 次”可作为快速定位色相条的参考。

ZL 次数 = round((98.1 - Hue bar percent) / 0.486)
